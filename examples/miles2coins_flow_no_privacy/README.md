# Miles2Coins - Example Flow (Without Privacy)

The instructions below describe how to execute a typical transaction flow (without privacy) in Miles2Coins.

## Prerequisites
See the [README.md](https://github.com/dalmendra/Miles2Coins/tree/main) in the `main` directory for instructions on installing the prerequisites.

## Overview

This example demonstrates a basic transaction flow in Miles2Coins without privacy. The flow involves two users, Alice and Bob, where Alice wants to sell miles (MilesToken), and Bob wants to buy miles using SampleCoins. Before interacting with Miles2Coins, preliminary transactions will be performed, including contract deployment, token minting, and balance verification.

1. Deploy the SampleCoin contract (`SampleCoin.sol`) - Implements a fictional stablecoin used as the exchange currency in the application.
2. Deploy the MilesToken contract (`MilesToken.sol`) - Manages tokenized airline miles.
3. Deploy the Miles2Coins contract (`Miles2Coins.sol`) - Implements the core functionality of Miles2Coins. 
4. Mint MilesTokens to Alice.
5. Mint SampleCoins to Bob.
6. Check Alice's and Bob's balances for MilesToken and SampleCoin.
7. Alice places an offer to sell MilesTokens.
8. Bob lists the available offers.
9. Bob accepts Alice's offer, completing the trade between Alice and Bob.
10. Check Alice's and Bob's balances for MilesToken and SampleCoin after the transaction.
11. Query transactions on the blockchain. Since privacy is not applied in this example, all transactions are fully visible.

## Step-by-step Example Execution

This step-by-step guide should be followed after installing the [prerequisites](#prerequisites). Steps labeled `0.x` are preparatory and must be executed before running the actual example flow.

0.1. Open a terminal and navigate to the application directory.  
0.2. Compile the smart contracts using Hardhat:
   ```bash
   > npx hardhat compile
   Compiled 18 Solidity files successfully (evm target: paris).
   ```
0.3. Start the Hardhat Network Node:
   ```bash

   ========

   Any funds sent to them on Mainnet or any other live network WILL BE LOST.

   Private Key: 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80

   Private Key: 0x59c6995e998f97a5a0044966f0945389dc9e86dae88c7a8412f4603b6b78690d

   ```  
	> **Note:** The accounts used in this example are automatically generated by the Hardhat node:
	> - **Account #1 → Alice**  
	> - **Account #2 → Bob**  

0.4. Open a new terminal window, navigate to the application directory, and start the Miles2Coins API.  
   ```bash
   node api.js
   Server running on port 3000
   Connected to network: unknown (chainId: 1337)
   ```
	> **Note:** In this example, the Miles2Coins API runs locally on TCP port 3000, and requests will be made via HTTP to this local port.  

0.5. Open Postman and import the [Miles2Coins collection](Miles2Coins.postman_collection.json).  

	> *Note:* This guide uses the [Miles2Coins collection](Miles2Coins.postman_collection.json) to simplify HTTP requests in Postman. However, these requests could also be performed using `curl` or another HTTP client. The requests interact with the Miles2Coins API, which processes them on the locally deployed blockchain.

1. Deploy the SampleCoin Contract. In Postman, run: `01_deploySampleCoin`.
2. Deploy the MilesToken Contract. In Postman, run: `02_deployMiles`.
3. Deploy the Miles2Coins Contract. In Postman, run: `03_deployMiles2Coins`.
4. Mint 10,000 MilesTokens to Alice. In Postman, run: `04_mintMiles`.
5. Mint 50,000 SampleCoins to Bob. In Postman, run: `05_mintSampleCoin`.
6. Check Alice's and Bob's Balances. In Postman, run: `06_checkBalances`.
7. Alice Places an Offer to Sell MilesTokens. In Postman, run: `07_placeOffer`.
8. Bob Lists the Available Offers. In Postman, run: `08_listOffers`.
9. Bob Accepts Alice's Offer. In Postman, run: `09_acceptOffer`.
10. Check Balances After the Trade Transaction. In Postman, run: `10_checkBalances`.
11. Query Transactions on the Blockchain. In Postman, run: `11_readTransactions`. Since privacy is not enabled in this example, all transaction details are visible. The blockchain blocks are read directly and decoded using the ABI of the Miles2Coins, MilesToken, and SampleCoin contracts.
	> The full response from the `readTransactions` request is available in the [readTransactions.log](readTransactions.log) file.

## **Additional Files in This Example**
- **[Miles2Coins.postman_collection.json](Miles2Coins.postman_collection.json)**: JSON file to be imported into Postman for simplified HTTP request execution.
- **[hardhat_output.log](hardhat_output.log)**: Contains the full output from the Hardhat node, showing blockchain activities.
- **[miles2coins_api.log](miles2coins_api.log)**: Contains all logs from the Miles2Coins API.
- **[readTransactions.log](readTransactions.log)**: Stores the response from the `readTransactions` request, displaying blockchain transaction data transparently, since privacy is not applied in this example.
- **[requests_and_responses.log](requests_and_responses.log)**: A complete log of all executed requests and their corresponding responses.
